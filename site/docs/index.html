Getting started

Install PhishGuard, make it your default browser, and every link you click in another app is checked first. It takes about two minutes and needs no admin rights.

What you need

  • Windows 10 or Windows 11.
  • Google Chrome or Microsoft Edge installed. Windows 11 already includes Edge. PhishGuard uses it, with a throwaway profile, as its hidden sandbox browser.
  • About 280 MB of disk space.

Install

  1. Download the installer. Get PhishGuard-Setup-1.1.1.exe from the latest release.
  2. Run it. It installs for your Windows account only, so it does not ask for admin rights.
  3. If Windows SmartScreen warns you that the publisher is unknown, choose More info, then Run anyway. The installer is not code-signed yet, because a Windows code-signing certificate costs money every year. You can check the file against the .sha256 fingerprint published next to it, or build it yourself from the source code.

Make PhishGuard your default browser

This is what puts PhishGuard between your apps and your browser. Links you click inside your browser stay there; links from WhatsApp, Discord, Outlook, PDFs and other apps come to PhishGuard first.

  1. Open PhishGuard and go to Settings → General.
  2. Press Make PhishGuard my default browser. Windows opens its own Settings on PhishGuard's page.
  3. Press Set default. Windows only lets you change this yourself, which is a good thing.

Choose your real browser

In Settings → General, pick the browser safe links should open in: Chrome, Edge, Brave or Firefox. PhishGuard starts that browser directly, so links never loop back into PhishGuard.

Everyday use

  • It starts with Windows, quietly, so the first link you click is already checked. You can turn this off in Settings.
  • Its shield icon sits next to the clock. Click it to open PhishGuard. Right-click it to check a link you copied, switch Start with Windows on or off, or quit.
  • Sites you trust open straight away, in about a quarter of a second. Everything else gets the full check, usually in two to three seconds.
  • It updates itself. See Updates.

Several people on one PC

On first start, choose Several people. Each person signs in with their own account, as an admin or an analyst, and the two roles get different rights. Every change is written to an audit log.

Uninstall

Use Settings → Apps → Installed apps → PhishGuard → Uninstall in Windows. The uninstaller asks whether to delete your history and settings too (%LOCALAPPDATA%\PhishGuard); the answer defaults to keeping them. Then pick a new default browser in Windows Settings.
