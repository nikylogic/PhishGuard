The web link checker

The checker on the home page runs PhishGuard's address rules in your browser. Here is exactly what it checks, what it sends where, and what only the Windows app can catch.

What it checks

  1. The address, with the same rules as the Windows app: look-alike brand names, a brand name on someone else's domain, risky domain endings, hidden @ tricks, link shorteners, IP-logger links, bait words and more. Every rule is on What it detects.
  2. The public phishing lists: about 380,000 reported phishing domains and addresses from phishunt.io and Phishing.Database, refreshed every 6 hours.
  3. The website's age, from the domain's official registry. A site registered in the last 30 days adds points; a domain nobody has registered means the link is dead.

What it sends, and where

  • The full link never leaves your browser. The rules run on your device.
  • Phishing lists: your browser computes a fingerprint (SHA-256) of the address and downloads one of 256 small files, picked by the first two characters of that fingerprint. The file is the same for thousands of addresses, so it reveals nothing about yours. The lists are stored as fingerprints too, so this site never publishes live phishing links.
  • Website age: only the domain name, such as example.com, goes to the official registry for its ending, found through IANA's public directory. Well-known sites, brands' own domains and free hosting are never looked up.
  • Sharing a result gives a link ending in #check=…. The part after # stays in the browser and never reaches the web server.

Same rules as the app

The checker is a direct port of the engine's address rules, fed with data the engine exports on every deploy. An automated test runs 65 links through both, from fake banks to Cyrillic look-alikes and javascript: links, and requires the same findings, words and score.

What only the Windows app can see

An address shows where a link goes, not what the page does. The checker cannot see:

  • a fake login form on an address that looks harmless;
  • a malware download, or a file whose name lies about what it is;
  • fake virus alerts, keyboard traps, "copy this command" scams and crypto-miners;
  • redirects that only happen when the page loads.

The Windows app opens the page itself in a hidden browser, so it catches all of these too. A Clear result here means the address shows no warning signs; it is not a promise that the page is safe.
