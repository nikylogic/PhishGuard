Updates

PhishGuard keeps itself up to date, and installs an update only when it carries PhishGuard's digital signature.

How it works

  1. Ten minutes after it starts, and then every 12 hours, PhishGuard asks GitHub for the latest release.
  2. If there is a newer version, it downloads a small description of the release and its signature.
  3. It checks the signature with the public key built into the app. Only the holder of PhishGuard's private key can make a valid one.
  4. It downloads the installer from PhishGuard's own GitHub releases and checks its size and SHA-256 fingerprint against the signed description.
  5. When no link is being checked, it installs silently, keeping your history and settings, and starts again. A notification says when it is done.

What is refused

  • A release without a valid signature, or with a signature for different contents.
  • An installer whose size or fingerprint does not match.
  • A download from anywhere but PhishGuard's own release page.
  • An older version than the one installed: updates never go backwards.

Your choice

In Settings → General → Updates choose Install automatically (the default), Download, then ask me, or Off. Check now looks straight away.

Upgrading from 1.1.0

Version 1.1.0 has no updater. Install the latest release once by hand; from then on it updates itself.
