Attacking PhishGuard itself

A tool that opens dangerous links must not become the way in. A security self-test starts a real engine, real fake attack sites, the real sandbox and a real Chrome window, and throws 63 attacks at it: network exposure, DNS rebinding, cross-site requests, authentication, SQL injection, path traversal, unsafe links, parser confusion, server-side request forgery, script injection, sandbox escapes, prompt injection, the link launcher and password guessing. All 63 are stopped.

One real problem was found while building that test and fixed: a backslash trick that made a link look like a trusted site to the app but open a different site in Chrome.
