    Questions

    How do I check if a link is safe?

    Paste it in the box above. It checks the address with the same rules as the Windows app, looks it up in about 380,000 reported phishing domains, and asks the registry how old the website is.

    Is my link sent to a server?

    No. The check runs in your browser. Only the domain name goes to its official registry, to read the website's age.

    What does the Windows app do that the website cannot?

    It opens the page itself in a hidden browser first, so it also catches fake login forms, malware downloads and fake virus alerts.

    Is PhishGuard free?

    Yes, for personal use and for non-profits. The full source code is on GitHub.

    Does it replace my antivirus?

    No, keep both. Antivirus guards your files; PhishGuard guards the click.
